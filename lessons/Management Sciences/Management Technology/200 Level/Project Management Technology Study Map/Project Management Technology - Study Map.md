## Three formulas that connect the whole course

- **Expected value of an estimate (PERT):** (optimistic + 4 x most likely + pessimistic) / 6. Used for activity duration and for cost.
- **Variance and performance indices:** CV = EV - AC; SV = EV - PV; CPI = EV / AC; SPI = EV / PV.
- **Present value:** a future cash flow X in year n is worth X / (1 + r)^n today. NPV adds these up and subtracts the cost.

## How the topics flow in a real project

Stakeholders set the need -> the **plan** and **WBS** define the work -> the **schedule** (CPM/PERT) and **cost estimate** set time and money -> **funding** is arranged and appraised (NPV, IRR) -> **execution** is controlled with earned value, change control and risk reviews -> **closing** records lessons learned.
